# Aero Edge Media — website (static + PHP)

![Aero Edge Media website](docs/screenshot.webp)

Static version of the **Aero Edge Media** agency website — services, pricing, FAQ, testimonials and partnership pages — with PHP handlers for the contact and newsletter forms.

- **Tech:** HTML · CSS · JavaScript · PHP · MySQL
- **My role:** customised the template into the company site, connected the forms, deployed on Hostinger
- See also the Django version: [aero_website](https://github.com/kaviyarasu-codes/aero_website)

## Setup
Copy `includes/config.example.php` to `includes/config.php` and add your database details. `config.php` is never committed.
